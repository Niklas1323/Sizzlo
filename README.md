# Sizzlo

**Learn. Cook. Level Up.** A gamified cooking school app: general cooking
skills first, a recipe project to practise them, optional real cooking after.

## In this repo

| Folder | What |
|---|---|
| [`backend/`](backend/README.md) | Profile backend: XP, stars, weekly cooking streak with Holiday Saves, achievements, Skill Passport, cooking logs, settings. Node + SQLite, with tests. |

The UI designs live in a separate design canvas for now.
